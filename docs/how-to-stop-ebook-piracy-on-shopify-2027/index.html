Two ways to protect an eBook

Encryption DRM or social DRM?

Encryption DRM (Adobe, LCP, Kindle)

  • Opens only in apps that support the DRM
  • Buyers often need an account, a reader app or an activation
  • Makes copying harder; tools to remove it exist
  • Higher support work: activation and device questions

Social DRM (watermark)

  • Opens in any app or e-reader for the format
  • Buyers need nothing extra: no login, no special app
  • Does not lock the file; makes sharing traceable
  • Low support work, common for direct sales

How a personal copy works

Sealed twice: a visible note and a hidden identifier

When someone buys, a new copy of the file is made for that order. Pageseal does this for eBooks, PDFs and audiobooks.

Layer 1 · visible

A note page with the buyer's name and order number, for example “This copy was made for Alex Sample, Order #1001”. Everyone who opens the file sees whose copy it is.

Layer 2 · invisible

A hidden identifier that stays in the file, even if someone deletes the note page. The copy stays traceable.

Every format you sell

EPUB (reflowable and fixed layout), PDF and audiobooks as MP3, M4B, M4A or a ZIP of MP3s. One sale covers all formats of a book.

Before you choose an app

What a good eBook watermark should do

Protection that annoys honest readers or breaks the book costs you more than it saves.

  • Keep the book intact on every reader, including fixed-layout picture books
  • Show the buyer's name calmly and respectfully, no shouting banners
  • Carry a hidden identifier that survives if the note page is deleted
  • Let you look up a found file yourself, without emailing a support team
  • Work for every format you sell: EPUB, PDF and audiobooks

Delivery settings

Delivery settings that close the easy leaks

Protection inside the file works best with a delivery that buyers do not need to work around.

  • Download limit per buyer, for example five or ten
  • Link expiry: choose how long the link is valid
  • Blocked after a refund: the link stops working
  • Download button on the thank-you and order status page
  • Delivery email in your shop's name, logo and colours
  • No account for buyers: no login, no extra app
  • Release day for pre-orders: no download before it (from Starter)

Common mistakes

Four mistakes that make eBook piracy easy

Same file for every buyer

Without buyer details inside, a shared copy cannot be traced to anyone, so there is no reason to hold back.

Only a visible note

A note page can be deleted. Without a hidden identifier, the trace is gone with it.

Links that never close

No download limit, no expiry, no block after a refund: a forwarded link keeps working for anyone who has it.

Locking out honest readers

When buyers need an account, a reader app or an activation, support work grows.

FAQ

eBook piracy on Shopify: questions sellers ask

Can I stop eBook piracy completely?

No. Nothing stops sharing completely. A personal copy with the buyer's name makes sharing less likely, and the hidden identifier lets you trace a shared file to its order.

Can a watermark be removed?

A visible note page can be deleted. That is why Pageseal also adds a hidden identifier that stays in the file, so the leak search still finds the order.

Does the buyer need an account?

No. The buyer downloads a normal file from the thank-you page or the email. No login, no extra app.

Can I sell eBooks on Shopify without an app?

Not automatically. Shopify has no built-in file delivery, so you need an app. Protection apps also personalise the file.

FAQ

More questions about protected eBooks

Does a watermarked eBook work on Kindle?

Yes. Kindle buyers do not need a MOBI file any more: a personalised EPUB can be sent to a Kindle with Amazon's Send to Kindle, like any EPUB.

Which apps open the personal copy?

Any app or e-reader that opens EPUB, for example Apple Books, Google Play Books, Kobo, Tolino, PocketBook and Thorium. PDFs open in any PDF reader.

Is social DRM legal in the EU?

Personalising a copy uses the buyer's name, which is personal data. Tell buyers about it and process it under a data processing agreement; Pageseal provides one.

Can I protect audiobooks the same way?

Yes. Pageseal personalises MP3, M4B and M4A files and ZIPs of MP3s and delivers them with the eBook in one order.
